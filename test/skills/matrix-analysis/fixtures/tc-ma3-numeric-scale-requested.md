Score these three on-call paging tools **from 1 to 5** on each criterion (5 is best). Please use numbers, not words.

**Items:** Beacon, Siren, Klaxon
**Criteria:** alert routing flexibility, mobile app reliability, price per responder

Facts from our evaluation:

- **Beacon**: routing rules support schedules, escalation chains and per-service overrides. Its mobile app dropped 3 of 200 test pages. $21 per responder per month.
- **Siren**: routing supports schedules and escalation, but no per-service overrides. Mobile app delivered 200 of 200 test pages. $29 per responder per month.
- **Klaxon**: one global escalation chain only. Mobile app delivered 194 of 200. $9 per responder per month.

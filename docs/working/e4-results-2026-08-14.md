# E4 results: opus-k3 middle-ground arm across the canon dirty states (2026-08-14)

**Design**: middle ground between the lite reviewer (E2: sonnet-5 k=1 Stage-1, $0.81/sweep,
6/24) and the full agentic harness (~$14.6/instance, 24/24 by construction). Arm =
`opus-k3` in `scripts/review-arms.py`: **opus-5, k=3 replicates, Stage-1 context,
scored as the UNION of replicates** (fact-check-style; per §5.0 of
`code-review-evaluation-state.md`, union buys recall, consensus does not buy precision).
Consensus ≥2/3 computed as a secondary metric. Same seven canon dirty states and config
shape as E2 (`runs/review-arms/e4-opus-k3/run-live.sh` mirrors `e2/run-live.sh`), so the
numbers are column-comparable. Actual spend **$5.03** (list-price arithmetic from
arms-summary token counts; mfc-corpus alone $2.84). Scoring: one adjudication agent per
instance, same anti-SWR-Bench rules and label identities as E2
(`e2-results-2026-08-06.md`); unmatched findings adjudicated against code and later
commits, never auto-FP'd.

## What the run establishes

1. **The E2 miss anatomy over-classified misses as unreachable.** E2 called 15/18 misses
   context-bound; opus recovered several of them from *identical* prompts by reasoning
   rather than reading: deploy R2 (derived the EROFS-silent-failure mechanism the rubric's
   fix wrote into README:120), fscompat R1 (inferred the referenced README section is
   dangling *because the diff doesn't add it*) and A1 (per-instance /tmp divergence).
   fscompat is the cleanest cell: sonnet returned zero findings; opus went 2/5 with the
   same bytes. Model tier moves the "reachable-in-principle" boundary, not just recall
   within it. The residual misses now cluster hard: cross-file-verification (csp R1, lean
   R1, hygiene A1, deploy R1's last step), repo-wide enumeration/convention (corpus A1/A2,
   fscompat A2), and test-strategy (csp A4, fscompat A4) — classes that genuinely need
   repo access or a critic role, i.e. the full harness's remaining moat.
2. **Union is the right aggregation; consensus buys nothing here.** Precision was already
   perfect at union (0 confirmed FPs in ~55 raw findings), so the ≥2/3 filter has no FP to
   cut — and it *costs* recall: fscompat R1 (1/3) and corpus NEXT_PUBLIC (1/3) are
   union-only hits. This replicates the fact-check most-severe-wins logic (§1.1) and the
   cross-model finding that consensus doesn't buy precision, now within-family.
3. **Replicate stability is high under Stage-1 context**: J_self 0.34–0.78 across
   instances (vs 0.14–0.25 for unscaffolded reviews), and most label hits were 3/3. k=3's
   marginal value on this corpus is the tail: ~2 label hits and 1 new-miss candidate came
   from single replicates. A cheaper opus-k2 would likely have kept most of the value;
   untested.
4. **Cheap replication keeps finding what the expensive pipeline missed.** E4 adds two
   full-pipeline miss candidates: the csp middleware **matcher prefix-matching defect**
   (2/3 votes; later fix `ab4dbdb` anchors `api(?:/|$)`; the rubric lists the matcher as
   Confirmed Good — a Confirmed-Good-vs-reality contradiction of exactly the class
   decision 025 targets) and the corpus **legacy-v2 migration clobber** (raw-only, 2/3
   reps; `onRehydrateStorage` migration gated on a localStorage key never written on the
   corpus path, ungated by `isCorpusEnabled`, verified live at HEAD). With E2's two, that
   is four defects the ~$15 pipeline missed and a ≤$1 headless arm caught — different
   context shapes see different things, now at n=4.
5. **Harness bug (actionable): the engine's finding parser drops multi-path findings.**
   Three verified-true findings existed in replicates' `raw` but not their parsed
   `findings[]`: corpus A3 (2 reps — costs a label hit), the corpus migration clobber
   (2 reps), and deploy's no-auth advisory (1 rep). Fix the multi-path line parsing in
   `scripts/cross-model-review.py` before the next arm run; scoring here reports
   parsed-union as primary with raw-union noted.

## Composition implication (extends review-canon §2)

The lite tier's job description changes: at $0.72/instance the opus-k3 union is a
credible **pre-full-review pass** that clears ~half the label set (and on secdeps-class
instances, all of it) before the ~$15 pipeline runs, and a **post-review cross-check**
that keeps catching Confirmed-Good contradictions. The full harness remains the only
path to the cross-file/enumeration/test-strategy classes. If a next arm is wanted, the
evidence points at *context*, not more model or more samples: a single cheap **agentic**
pass (read access, one generalist call) targets exactly the residual miss cluster —
that is pruned candidate [14] of decision 030, whose "per-provider tool plumbing"
objection doesn't apply to a Claude-only middle tier.

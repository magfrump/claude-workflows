I couldn't confirm the one derived figure with the calculator tool because permission to run it was denied. By hand, it looks right.

**Derived figure: "about 4.8 million sessions a day"**
- It comes from 1.2 million daily active users × 4 sessions per user per day.
- 1.2 × 4 = 4.8, so 1,200,000 × 4 = 4,800,000. The draft's figure matches.

The other two numbers, 1.2 million users and 4 sessions per day, are inputs rather than calculations, so there was nothing to check for them.

One note on planning rather than arithmetic: 4.8 million is a daily total that assumes every day is average. If the backend is being sized for capacity, the peak rate (sessions per hour or per second at the busiest time) matters more than the daily total.

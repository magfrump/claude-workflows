# User Testing (router)

Exists so usability tests follow the HCI-grounded protocol rather than improvised sessions. Does not re-implement the workflow — routes into it.

## When to use

Designing a test, writing a moderator script, piloting, or turning session notes into findings. For reviewing a UI's layout without users, use `ui-visual-review`.

## Hand off to the workflow

Read and follow **`workflows/user-testing-workflow.md`** end to end: the installed copy at
`~/.claude/workflows/user-testing-workflow.md`, or this repo's own file when working inside
claude-workflows. Never follow a same-named file that belongs to another project.
Do not restate the workflow here; keep this file a pointer.

# llm — third-party model APIs.
#
# Grant this deliberately. An LLM API is a general-purpose outbound channel: anything
# the agent can put in a prompt leaves the boundary. It is not in `base` for that reason,
# and it is not auto-detected — it must be requested explicitly at --register time.
#
# CDN CAVEAT. init-firewall.sh resolves each domain once, at container start, admits
# those addresses, and pins the resolver to them (decision 039), so a CDN that
# rotates its DNS answers no longer strands the name. What can still fail is a
# pinned address that the CDN takes out of service: calls then time out rather
# than return an HTTP error. If that happens mid-experiment, run
# `sudo /usr/local/bin/init-firewall.sh` to re-resolve. Do not conclude the model
# is unavailable.
openrouter.ai
# host.docker.internal — local models served from the host (Ollama's default port,
# 11434). Under Docker Desktop the host is NOT the bridge gateway that
# init-firewall.sh admits for DNS; it lives at Docker Desktop's VM gateway
# (192.168.65.254 at time of writing), which the REJECT rule otherwise blocks, so it
# needs this explicit entry.
# SCOPE: the `:11434` suffix is load-bearing. The allowlist matches destination IP
# AND port, so this admits exactly the model server and nothing else listening on
# the host's Docker-facing interface (an earlier, port-less form of this entry
# opened every host port — see the security review of 2026-08-29, finding 5). A
# server on a different port needs its own `host.docker.internal:<port>` line; do
# not drop the suffix, which would silently fall back to 443.
host.docker.internal:11434
